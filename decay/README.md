\# Decay

\*\*Premises: Temporality & Feedback\*\*  
[https\://elakoten.github.io/decay/](https://elakoten.github.io/decay/)

\# Description:  
"Decay" is an interactive audio-visual experience that combines time based decay with transparent visual feedback. The user triggers audio-visual wave pulses by clicking the canvas or pressing alternative keyboard keys A-K. Over time, active waveforms organically fade and diffuse into soft, smudged chronological feedback trails.

\#\# How to Use  
1\. Open the live link in a browser  
2\. Click anywhere on the startup overlay to initialize the Web Audio engine.  
3\. Click on the canvas or use the keyboard keys A-K to generate wave notes and retro synth tones.  
4\. Use the system parameter sliders on the right panel to adjust decay speed, blur radius, harmonic strands, and base pitch frequency in real time.

\#\# AI Use Note  
\* \*\*Tools Used\*\*: Gemini (for web audio synth architecture troubleshooting, understanding how parameters are linked together, and improving the logical structure of the underlying theory).  
\* \*\*Correction Example\*\*: AI generated code placed wave impulses directly under random mouse click locations. I rejected this and corrected the code to add notes sequentially along the continuous oscillogram line, which accurately reflected the project's sequential timeline premise.
